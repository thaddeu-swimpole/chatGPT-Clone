# ChatGPT Clone

## About

This is a static ChatGPT clone interface created using HTML and CSS.

## Features

- Chat window
- User messages
- ChatGPT messages
- Text input field
- Send button
- Responsive design

## Design Process

I first created the basic structure using HTML.
Then I used CSS to create a clean and simple chatbot interface.

## Purpose

This project was created to understand the basic structure and layout of a chatbot application.

## Technologies Used

- HTML5
- CSS3

## Note

This is a non-functional static project.
The send button does not send real messages.
